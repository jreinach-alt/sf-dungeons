# refs — reference, NOT an asset

Images and notes here are **visual guidance supplied by the owner**. They are never shipped, never
traced, and never converted: shipped art comes from committed scripts (docs/dungeons/13 §6, 14 §2).
The licence and training provenance of a generated image are outside what this tree can verify.

| file | what | used for |
|---|---|---|
| `enemy_sheet_reference.png` | an owner-generated four-enemy sprite sheet (32×32, 3/4 top-down) | silhouettes, proportions, palettes and animation states for the four creatures in `docs/dungeons/17` |
| `enemy_art_guidance.md` | the owner's written brief for those four creatures | the spec of record for what each creature must be and do |
